# Security Policy

## Supported versions

Security fixes are applied to the latest published version of this repository.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues, discussions, or pull requests. Contact the repository owner privately through the contact method shown on the owner's GitHub profile and include:

- the affected plugin and version;
- a clear description and reproduction steps;
- the likely impact;
- a suggested remediation, if available.

Do not include real customer data, credentials, or destructive proof-of-concept material.
