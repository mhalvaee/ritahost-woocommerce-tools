# Contributing

Thank you for helping improve RitaHost WooCommerce Tools.

## Before opening a pull request

1. Keep each change focused on one problem or feature.
2. Preserve compatibility with WordPress 6.0+, PHP 7.4+, and current WooCommerce releases.
3. Follow WordPress coding and security practices, including capability checks, nonces, sanitization, and escaping.
4. Test the affected plugin both independently and, when applicable, under the shared RitaHost admin panel.
5. Do not include credentials, customer data, generated archives, or site-specific secrets.

For vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
